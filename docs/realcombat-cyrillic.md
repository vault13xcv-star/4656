# Кириллица в Windows-сборке

В архиве есть два способа запуска с читаемым русским текстом:

- **`OpenMW-Russian.cmd`** — для русской версии Morrowind и русских плагинов
  в кодировке Windows-1251. Включает `win1251` и встроенный шрифт MysticCards
  для интерфейса, книг и свитков. Шрифт содержит весь русский алфавит, включая Ё/ё.
- **`OpenMW-Cyrillic-Fonts.cmd`** — включает те же шрифты, сохраняя выбранную
  кодировку игровых данных. Подходит, если текст игры уже читается правильно,
  но введённое русское имя или текст модификации отображается квадратами.

Запускайте нужный файл из полностью распакованной папки сборки. Оба используют
ваши обычные игровые данные, модификации, сохранения и настройки OpenMW.
Они не редактируют `openmw.cfg`: параметры действуют только на этот запуск.
Обычный `openmw.exe` сохраняет прежний выбор кодировки и шрифтов.

В консоли используется встроенный DejaVu LGC Sans Mono; расширен набор
доступных кириллических символов, включая украинские и сербские буквы.
Лицензии шрифтов находятся в `resources/vfs/fonts` рядом с самими шрифтами.
Ввод с русской раскладки и вставка из буфера обмена используют штатный Unicode
OpenMW/SDL. Для ввода включите русскую раскладку Windows; русские названия
не меняют язык команд консоли.

Это поддержка отображения и ввода, а не перевод английской версии игры.
`win1251` выбирают по языку игровых файлов, а не по языку клавиатуры.
Русский профиль не подходит для французских/немецких плагинов в Windows-1252:
общая кодировка OpenMW не преобразует смешанные кодировки отдельных плагинов.

Проверка в игре: введите **«Ёжик, Щит и Яд»** в поле имени или сохранения,
проверьте русский диалог, книгу, свиток и вставку русского текста в консоль.
Если вместо русских букв видна последовательность вроде «Ïðèâåò», нужен
`OpenMW-Russian.cmd`. Если в игре верные буквы, а проблема только со шрифтом,
используйте `OpenMW-Cyrillic-Fonts.cmd`.
