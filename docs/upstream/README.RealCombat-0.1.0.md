# Real Combat 0.1.0

Прототип мода ближнего боя для OpenMW 0.51.0.

[Скачать RealCombat-0.1.0.zip](https://github.com/vault13xcv-star/4656/raw/refs/heads/downloads/real-combat-0.1.0/RealCombat-0.1.0.zip)

Распакуйте архив, подключите его папку `Data Files` в OpenMW и включите `RealCombat.omwscripts`. Подробная инструкция и настройки входят в архив.

Формулы и скрипты проверены автоматическими тестами с имитацией API. Проверка внутри игры пока не проводилась.

Контрольная сумма архива находится в `SHA256SUMS`.
