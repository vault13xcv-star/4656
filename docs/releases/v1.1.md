# Brutal Morrowind 1.1 — Windows x64

Основная стабильная версия мода на базе OpenMW 0.51. Все изменения текущего
рабочего билда включены в этот выпуск.

- Текстуры `burnt` и `poisoned` покрывают соответствующие тела; масштаб
  бесшовных узоров увеличен вдвое.
- Текстуры разрезов конечностей, пояса и продольных разрезов подогнаны под
  геометрию и реагируют на освещение.
- Расчленение огнём и холодом происходит без крови.
- Кувалда при смертельном ударе в торс может оторвать 3–5 случайных разных
  конечностей из рук, ног и головы, сохранив торс целым. Действует шанс из настроек.
- Сохранены рэгдолл, брызги и следы крови, настройки физики и текущая боевая система.

Скачайте `Brutal-Morrowind-1.1-Windows-x64.zip`, полностью распакуйте в отдельную
папку и запустите `openmw.exe`. Нужны данные Morrowind и настроенный OpenMW.
Игровые данные, лаунчер и редактор в архив не входят. Исходный код и SHA256
приложены к релизу.

Движок, DLL и игровые ресурсы взяты из текущего билда без повторной компиляции.
Пройдены 1402 компонентных теста, четыре группы тестов физики/расчленения и
38 из 39 интеграционных тестов Windows. Один тест ожидал прежнего разрыва
торса кувалдой; его ожидание исправлено в исходниках, оригинальный результат
сохранён. Подробности — в `KNOWN-ISSUES.md` и `RELEASE-INFO.json` внутри архива.

Version 1.1 is the current stable release. Extract the entire Windows ZIP;
your Morrowind data and OpenMW configuration are required. The executable and
game resources are retained from the current build without recompilation.
The source archive, checksums and disclosed validation note are included.
