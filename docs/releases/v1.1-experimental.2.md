# Brutal Morrowind 1.1 Experimental 2

- Doubled the visible size of burnt and poisoned corpse patterns in both UV
  directions, preserving seamless stochastic blending and world lighting.
- Fire/frost explosions and severing no longer emit blood. This includes lethal
  enchanted-weapon hit sprays, wound fountains and surface deposits.
- The blood rule persists after flames expire, physics freezes, save/load and
  changes to blood/status settings. Ordinary, poison and shock bleeding remain.
- Successful two-handed hammer torso dismemberment randomly detaches 3–5
  distinct extremities (arms, legs and head). The torso stays intact, with no
  waist split or intestines. The configured dismemberment chance still applies.

All five original gore DDS files and all six blood DDS files are unchanged.
Combat damage, loot and blood performance budgets are unchanged.
V1.0 remains the stable Latest release; this update uses the separate 1.1 branch.

Extract the entire Windows ZIP into a separate directory. Morrowind game data
and your existing OpenMW configuration are required; use copies of saves.

The original Windows run passed 4 physics/render groups, 1402 component tests
and 38/39 native integration tests. One integration expectation still required
the intentionally removed hammer waist cut. Its source is corrected; the
retained engine is published without recompilation. See the included
`KNOWN-ISSUES.md` and `RELEASE-INFO.json` for the original result and provenance.
